# Inbox cleanup: your standing instructions

Copy this file to `inbox-rules.md` (which is not committed) and write your own rules below
the line. `npm run watcher add inbox-cleanup` pastes them into the task when it installs the
watcher, so after an edit run `npm run watcher remove inbox-cleanup` and add it again.
Everything below the line is used as is. Leave it empty for no extra rules.

---

Move these to Trash, never to permanent deletion, including similar mail from the same kinds of senders:
- Newsletters and form-letter marketing from Example Bank (news.examplebank.com). Leave alone anything that is clearly personal and one to one, an account statement, a security or fraud notice, or a tax document. If unclear, leave it and list it under "Left alone, unsure".
- Job alert mail (jobalerts-noreply@example.com and similar job recommendation mail).
