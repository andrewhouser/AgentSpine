# Niche watch: the pages to look at each week

Copy this file to `watch-list.md` (which is not committed) and list your own pages below the
line. `npm run watcher add niche-watch` checks the list and pastes it into the task when it
installs the watcher, so after an edit run `npm run watcher remove niche-watch` and add it
again.

One page per line, as `- Name: https://address`. At most 5 pages, https only, and each is the
exact page to read (a "what's on" or "news" page works better than a home page). Lines that
are not list items are notes to yourself and are ignored. The examples below are indented so
that they are not read as pages: remove the indent, or write your own.

---

    - Harbor Room: https://harborroom.example/calendar
